# 05 · 奶茶广告：分镜草案（待批）

## A. 概念

- **品牌**：「啵茶 BOCHA」，为这个案例虚构，与真实品牌无关，README 里会写明。
- **产品线（第一轴 `flavor`）**，共四款：
  - `brownsugar` 黑糖珍珠：深褐色的虎纹糖浆顺着杯壁挂下来，配黑珍珠；
  - `jasmine` 茉莉奶绿：淡青白的茶汤，配白玉珍珠；
  - `strawberry` 草莓啵啵：底部一层粉红果泥，配半透明的红色爆爆珠；
  - `taro` 芋泥：淡紫色，杯壁抹着芋泥纹。
- **画面与情绪**：高速摄影质感的微距，冷白的影棚逆光，透明 PP 杯，杯壁挂满冷凝水。节奏轻快、清凉、解渴，每款用自己的主色做背景渐变。

## G. 引擎工作

### (a) 必须先做的引擎改动（单独立项，各带引擎测试）

1. **`factory/engine/bake.js`**：`bake({ seed, dt, t1, init, step })` 在 `setup` 里用定步长把模拟跑完，存成 Float32Array 表；`sampleBake(table, t)` 在两帧之间线性插值，超出范围就钳住。测试要断言：
   - 同样的参数烘两次，逐字节相同；
   - 在节点上取值等于存下的状态；
   - 按乱序、倒序取值，结果和顺序取一样；
   - 超出范围时钳住；
   - 步数等于 ⌈t1/dt⌉；
   - `step` 拿到的随机数只来自 `rng.js`。

   另外要控制烘焙耗时。`openFilm` 的超时是 90 秒，换口味还要重跑 `setup` 和预热，所以每次烘焙建议 < 1.5 s。可以让 `check.mjs` 顺手打出烘焙耗时，这一项可选。
2. **把 03 的 `js/glass.js` 抽成共用的折射模块**（如 `factory/engine/refract.js`）。它不是直接挪个位置就行：现在的代码写死了 `bottle.js` 的八角棱柱 `SHAPE`、`RIPPLE` 和 `DIMS`，焦散也是按棱柱写的。要改成接收一个「形状描述」：
   - 凸棱柱（03 用）；
   - 圆台薄壁（05 的 PP 杯，杯口比杯底大）；
   - 分层（世界 → 内容物 → 液体 → 容器 → 前景）照 03 保留，并加一层给冰块。
   
   测试要断言：
   - Node 里的 JS 版射线求交（进出距离、法线）和棱柱、圆台的解析解一致；
   - 生成的 GLSL 能在带 `#define` 的两种形状下拼出来；
   - 03 迁过去以后回归：`check.mjs 03-perfume` 全过，同一 GPU 上迁移前后的 snap 逐字节相同（至少 PSNR > 45 dB）。

音频不用改。冰块碰撞用 `bell`（`ratios` 非谐波）+ `click`，刺破封膜用 `click` + `noise`。拟音是 07 的活，这里不需要。

### (b) 留在成片里的

杯子、封膜、吸管的建模，茶汤的着色器（颜色、奶纹、虎纹），冷凝水，四款口味的外观，字幕、配乐、配音。

各效果怎样做到确定性：

| 效果 | 做法 |
|---|---|
| 珍珠落下（约 60 颗） | **烘焙模拟**：球–球碰撞 + 球–圆台碰撞 + 阻尼，dt = 1/240，跑到 2.5 s；InstancedMesh 按 t 查表。模拟和口味无关，同一张表四款共用 |
| 奶花 | **做假，但是闭式**：液体着色器里用随 t 变化的旋度噪声做域扭曲，再加一个从上往下推进的密度前沿。不做流体模拟 |
| 冰块 | **闭式**：落下 + 阻尼弹簧沉浮 + 两次碰撞的冲量都写死；液面起伏用 03 `rippleHeight` 那套公式 |
| 冷凝 | **闭式**：水珠的位置和半径用 `rand(seed, i)`，半径随 t 长大；滑落的那颗走预设路径；做成杯壁的法线/粗糙度贴图 |
| 吸管刺破 | **闭式**：封膜按解析的凹陷曲面下沉，0.75 s 换成预先切好的撕裂瓣网格；吸管用缓动下压 |

## H. 风险与简化方案

- **最容易难看的是奶花**：假流体很容易看起来像烟雾。另外奶茶本身不透明，透过杯子看进去主要是散射，折射的看头有限。
  - 简化方案：放弃 3D 奶花，改成「分层下沉」：奶层带着一条闭式的波浪界面往下推，黑糖款配杯壁虎纹。这个画面观众本来就熟悉。
- **最慢的是多层折射叠冰块**：画一帧要多走一遍，再加上液体里的体积步进，1080p 下 GPU 负担最大。不过 03 实测的瓶颈在 CPU（PNG 编码和 x264），这一项风险中等。
  - 简化方案：冰块不进折射层，只用带环境反射的 `MeshPhysical`；液体只用单次吸收，不做步进。
- **珍珠堆叠抖动**：烘焙时可能不收敛。
  - 简化方案：用 rng 预先摆好静止的堆叠位置，每颗珍珠走闭式的抛物线落下，再缓动到自己的位置。这样 `bake.js` 就可以晚点做。
- **工作量粗估**：
  - 引擎：`bake.js` 0.5–1 天；共用折射模块加 03 回归 2–3 天。
  - 成片：6–8 天，其中液体和奶花占 2–3 天。
