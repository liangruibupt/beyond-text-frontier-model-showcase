# 10 · 直播间秒杀 motion pack：分镜（已批）

## A. 概念

- **场景 H**（`factory/Video-Factory.md`）：直播带货的屏幕包装——「3-2-1 上链接」、红包雨、库存条清空到「已抢光」、弹幕滚动、购物车弹窗。重点是一套**可复用的图形组件**，片子是这套组件的演示。
- **品牌**：沿用 04 / 08 虚构的购物 App「有集 Youji」，直播间叫「有集直播」，与真实平台无关，README 写明。
- **产品线（第一轴 `item`）**：沿用 08 的三件商品，价格照搬 04 `catalog.js`（整数）：
  - `lantern` 营地灯：¥189 → 秒杀 ¥129；$28 → $19
  - `headset` 电竞耳机：¥499 → ¥359；$75 → $55
  - `beans` 瑰夏咖啡豆：¥169 → ¥129；$25 → $19
- **画面**：PC 端直播间的样子。背景是代码 3D 影棚：桌上一个转台放着商品，背后是虚化的环形补光灯光斑和「有集直播」霓虹招牌。**画面里不出现主播**，主播只出声音（见第 I 节问题 2）。所有图形都叠在这个背景上。
- **情绪**：热闹、紧张、抢购感。有集橙 `#ff7a1a` + 秒杀红 `#ff2d3d` + 金色。

## G. 实现

### (a) 引擎

不用改 `factory/`（TASKS.md 里 10 也没列引擎能力）。分两层做，都是现有能力，做法和 08 耳机的游戏 HUD 一样：
- 文字（倒计时数字、上链接、价格、弹幕、在线人数、已抢光）走引擎的 2D 文字层，用 `pop` / `in` / `out` / `box` / `panel` / `strike`。弹幕要逐帧横移，文字层如果做不顺，就改画进 CanvasTexture；
- 图形（红包、金币、心形、库存条、弹窗底板、印章）是挂在相机前面的一组 3D 平面，贴 CanvasTexture（08 的手机屏幕就是这么画的），这样能有透视、光晕和景深；
- `drift`（`particles.js`）和 `rng.js`：红包、金币、点赞心形；
- `audio.js` 现有的音色：`click`、`bell`、`plink`、`pluck`、`noise`。

### (b) 片子里的「motion pack」

放在 `10-live-flash-sale/js/pack/`，每个组件是纯函数 `(t, 参数) → 画面`，可以单独拿出来用。每个组件带测试：
| 组件 | 做法（都是闭式，按 t 直接算，不需要烘焙） |
|---|---|
| `chrome` 直播外框 | 在线人数 = 起点 + 按 t 的缓动增量，取整显示；点赞心形用 `drift` |
| `danmaku` 弹幕 | 每条评论 i 由 rng 定好车道、出现时间和速度，x = 1 − (t − t0)·v；`stock` 段把速度乘 1.8 |
| `countdown` 倒计时 | 每个数字在自己的拍点上做「放大 → 回弹 → 淡出」，冲击波圆环按 t 扩散 |
| `cart` 购物车弹窗 | 弹簧缓动的解析解从底部弹上来；点击水波纹按 t 扩散；角标 +1 回弹 |
| `envelopes` 红包雨 | 约 40 个红包，`drift` 下落 + 绕轴翻转；拆开的那一个走预设路径，金币是闭式抛物线 |
| `stockbar` 库存条 | 宽度 = 缓入曲线从 37% 到 0；「仅剩 N 件」取整；「已抢光」印章做放大 → 砸下 → 轻抖 |

测试：每个组件同一 t 算两次结果相同、可以乱序取样、关键时刻落在拍点上；弹幕和弹窗在 16:9 和 1:1 都不压进平台 UI 的红区；文字适配用 `approxMeasure`。

## H. 风险与简化方案

- **画面太「平」**：全是 2D 图形，容易像 PPT。做法是背景保持 3D 影棚、浅景深和转台转动，图形加一点透视和光晕；样张不够热闹，就再加一层前景的彩带。
- **弹幕挡住商品**：弹幕带限定在画面上方 40%，商品的构图避开这一条；`stock` 段弹幕加速时也不进下半屏。
- **太吵**：音效多。每个命中点只给一个主音效，其余音效往下压，配音时整体再压低（引擎已经会自动压）。
- **工作量粗估**：6 个组件 + 影棚 2–3 天，镜头、配乐、配音和出片 2–3 天。不需要 AI 实拍，不需要动引擎。
