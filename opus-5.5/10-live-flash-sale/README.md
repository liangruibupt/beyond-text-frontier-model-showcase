# 10 · 有集直播：直播间秒杀 motion pack

有集直播间的 15 秒秒杀短片：真人主播在带货直播间里举起商品，画面上叠一整套秒杀图形组件，依次是倒计时「3-2-1 上链接」、购物车弹窗、红包雨、库存条清空到「已抢光」，还有一直在刷的弹幕。分镜见 [`docs/specs/2026-10-08-10-live-flash-sale-storyboard.md`](../docs/specs/2026-10-08-10-live-flash-sale-storyboard.md)（已批）。

> **虚构品牌**：「有集 Youji」和「有集直播」是虚构的购物 App，沿用自 04 / 08；商品、价格取自 04 的目录（`04-year-review/catalog.js`，只读引用）。片中的主播由视频模型生成，不是真人。
> 片中出现的所有品牌、商品、价格、弹幕和在线人数均为演示用途，并非真实。

## 做法：AI 实拍画面 + 代码图形层

真实的直播间本来就是「实拍画面 + 一层 UI」，这部片按同样的方式分两层：

| 层 | 谁做 | 内容 |
|---|---|---|
| 画面 | Opus 写提示词，**LTX-2.5** 生成 | 一位年轻的中国女主播在明亮的现代直播影棚里演示商品：打招呼、举起商品靠近镜头、放回桌上。画面里不要任何文字，顶部留出放弹幕的空间，片尾镜头给片尾卡留出空位 |
| 图形层 | Opus 写代码，factory 引擎逐帧叠加 | 直播外框、弹幕、倒计时、购物车弹窗、红包雨、库存条、「已抢光」印章、字幕、片尾卡、价签 |
| 声音 | 代码 | 120 bpm 配乐（命中点都落在 0.5 秒拍点上）+ Kokoro 主播口吻配音（中文 `zf_xiaoyi`、英文 `af_heart`） |

最早的代码版画面是 3D 影棚加转台上的商品，用户看过觉得「太丑」，所以改成 AI 实拍画面，图形层没动。代码版 `lantern` / `headset` / `beans` 还保留在仓库里，可以出片，但不在交付清单里。

## 15 秒版镜头

| 时间 (s) | 镜头 | 画面 |
|---|---|---|
| 0–2.5 | `room` | 主播打招呼，外框、点赞心形、弹幕依次出现，在线人数往上跳 |
| 2.5–5.0 | `count` | 3、2、1 分别在 3.0、3.5、4.0 秒砸下来，4.5 秒「上链接！」炸开 |
| 5.0–7.5 | `cart` | 主播举起商品，购物车弹窗弹上来：商品图标、秒杀价、划掉的日常价；6.5 秒点「立即抢」 |
| 7.5–10.5 | `rain` | 红包雨，9.5 秒一个大红包落到弹窗上拆开，金币炸开，盖「已领券」章 |
| 10.5–12.5 | `stock` | 库存条往 0 掉，弹幕越刷越快，12.0 秒「已抢光」印章砸下 |
| 12.5–15 | `end` | 片尾卡 |

6 秒 1:1 双11 版：倒计时 → 拆红包 → 双11 价签，不放「已抢光」，免得先说卖完再让人买。

## 模型对比

正式出片前，用营地灯的 `room` 和 `cart` 两个镜头对比了三个开源视频模型，详见 [`ai/report/BAKEOFF.md`](ai/report/BAKEOFF.md)：

| | LTX-2.5（蒸馏版 + FP8） | Wan 2.2 TI2V-5B | MiniMax H3 |
|---|---|---|---|
| 结果 | 2/2 成功，**选用** | 2/2 成功 | 0/2，生成流程接错了 ComfyUI 节点，没出画面 |
| 每段 GPU 时间 | 约 6 分钟 | 约 15 分钟 | — |
| 显存峰值 | 24.6 GB | 33.4 GB | — |
| 画质 | 最像随手拍的带货直播，脸和手自然，商品还原度高，画面无文字 | 单帧更精致，但像摆拍广告；背景纸箱冒出乱字，且这条路径不支持反向提示词 | — |

对比一共花了约 7 美元 GPU 费用；正式出片用了 36 段 LTX 片段（3 件商品 × 6 个镜头 × 16:9 / 1:1 两种画幅），约 20 美元。

## 交付

3 件商品 × 3 类交付 = **9 条**，文件名 `youji-live_<item>-ai_<cut>_<ar>_<lang>[_<promo>].mp4`：

| 商品 | 16:9 15 秒中文 | 16:9 15 秒英文首发 | 1:1 6 秒中文双11 |
|---|---|---|---|
| 营地灯 `lantern-ai` | ✓ | ✓ | ✓ |
| 电竞耳机 `headset-ai` | ✓ | ✓ | ✓ |
| 瑰夏咖啡豆 `beans-ai` | ✓ | ✓ | ✓ |

成片和封面在 `out/`（gitignore，不入库）；画廊读 `out/index.json`。LTX 原始片段已清理，重新渲染前要先在 GPU 上重新生成。

## 运行

```bash
npm run serve
# 预览：http://127.0.0.1:8765/10-live-flash-sale/?ar=16x9&item=lantern
# 画廊：http://127.0.0.1:8765/factory/gallery.html?film=10-live-flash-sale
```

- 轴：`item`（交付用 `lantern-ai` / `headset-ai` / `beans-ai`，代码版 `lantern` / `headset` / `beans`）· `lang`（zh / en）· `cut`（15 / 6）· `promo`（none / 1111 / launch），外加引擎的 `ar`、`vo`。AI 版要先把 LTX 片段放到 `out/ai/` 下才能预览。
- 生成 AI 片段：提示词在 `ai/shots.json`，LTX 环境和脚本在 `ai/ltx/`（`setup.sh`、`gen-all.py`，模型只加载一次连续生成）。用 g6e.2xlarge（L40S 48 GB，64 GB 内存）。
- 出片：

```bash
node factory/render.mjs 10-live-flash-sale --dry           # 先看清单
node factory/cloud.mjs up --hours 2
node factory/cloud.mjs run node factory/check.mjs 10-live-flash-sale --ar 16x9   # 1:1 再跑一次 --ar 1x1
node factory/cloud.mjs render 10-live-flash-sale --workers 1   # 单进程，避免黑帧
node factory/cloud.mjs down
```

长时间的生成和渲染脚本要用 `setsid nohup` 脱离 agent 运行，并定时把片段拉回本地：agent 被强制停掉时，清理钩子曾先关机，导致已生成的素材全部丢失。跑完要扫一遍各个区，确认没有残留的 GPU 实例。

## 实现

| 部分 | 做法 |
|---|---|
| 图形组件 `js/pack/` | `chrome`（直播外框，在线人数按 t 缓动）、`danmaku`（弹幕，同一车道像传送带一样排开，有逐帧不重叠的测试）、`countdown`（数字放大 → 回弹 → 淡出 + 冲击环）、`cart`（弹簧缓动的解析解）、`envelopes`（约 40 个红包下落翻转，金币走闭式抛物线）、`stockbar`（库存条 + 「已抢光」印章）。每个都是 `(t, 参数) → 画面` 的纯函数，可以单独拿出来用 |
| 叠加 `js/overlay.js` | 把组件画成挂在相机前的平面；整片关掉景深，泛光只作用在灯光和霓虹上，图形和文字不发糊 |
| AI 底图 | `js/world-ai.js` 把 LTX 片段逐帧当底图；`js/shots-ai.js` 给 AI 版调整倒计时、「上链接！」、字幕的位置，不压主播的脸（16:9 和 1:1 分别调） |
| 引擎修复 | `factory/engine/video.js`：多个视频片段共用一张贴图，原来按片段分开记「这一帧画过没有」，叠化时会串成另一个镜头的画面；改成按（片段, 帧）判断 |
| 确定性 | 所有动作都是（变体, t）的闭式函数；`check.mjs` 用正序 / 倒序渲染同一帧比对 |
