# 04 · 有集年度购物报告 —— 电商年度盘点视频工厂

这是一支 15 秒的「年度购物报告」短片。每年 12 月，虚构购物 App「有集 Youji」给每位顾客生成一支自己的年度盘点：把这一年的下单数据做成一段能直接分享的视频。六个镜头依次是：

- **open** 一面按日子排布的方块墙，方块顺着日期翻面，翻出这一年有订单的日子；
- **count** 硬切到年度订单总数滚动计数，数字滚完，一摞包裹落地；
- **months** 十二根柱子依次升起，每根是一个月的订单数，最高的一根（通常是 11 月）亮起；
- **top** 一张品类饼图扫出，最大的一块滑出，那件商品落进购物车；
- **title** 一枚年度称号奖牌落地（模型按数据起的「人设」标题）；
- **end** 片尾卡：标语与查看按钮，或双 11 到手价，或年度报告上线 + 分享券。

四位顾客各有自己的数据、配色、旋律和文案，人设标题由 Claude Opus 5.5 按数据写成。

同一个模板可批量出片，覆盖以下组合，每个都有带配音和不带配音两版：

- 三种画面比例（抖音 / 淘宝竖屏、主图方屏、Amazon 横屏）；
- 四位顾客；
- 中英两种语言；
- 15 秒和 6 秒两种长度；
- 三种片尾活动。

> 「有集 Youji」是为本案例虚构的购物 App，顾客、商品、价格、活动都是示例数据，与任何真实平台、个人或商品无关。姓名为虚构，配音与文案不假设任何人的性别（用「你 / you」）。

纯静态网页：原生 ES Module + [Three.js 0.170](https://threejs.org/)（importmap 经 jsDelivr 加载），无构建步骤。方块墙、包裹、柱状图、饼图、奖牌、商品模型、字幕和配乐都由代码程序生成；文案由模型预先写好并随仓库提交（`stories/*.json`），配音是预先生成、随仓库提交的 mp3。时钟、取景、字幕排版、后期、混音、预览页、批量出片和画廊都来自共用的 [factory 引擎](../factory/README.md)，本目录只有这部片子自己的数据、场景和镜头。

## 看点

| | |
|---|---|
| **一个模板，批量出片** | 4 位顾客 × 3 比例 × 2 语言 × 2 长度 × 3 活动，每个都能出带 / 不带配音两版。默认清单出其中 12 条交付片，一条命令出完，还能断点续做 |
| **数据驱动的画面与声音** | months 每根柱子的高度是那个月的订单数；柱子升起时弹一个音，音高按订单数映到五声音阶上，所以每位顾客的旋律都不同。open 的方块只翻出真有订单的日子；top 的饼图按品类订单数分块 |
| **模型写文案** | 人设标题和两句旁白由 [Claude Opus 5.5](https://www.anthropic.com/) 经 Bedrock（`converse` + 强约束的 `write_story` 工具）按数据写成，中英各为地道母语文案而非互译；`stories/*.json` 入库，出片时不再调模型 |
| **六个镜头** | 见下面的镜头表。每个镜头只由镜头本地时间决定：拖动时间轴、跳着看和顺序播放得到同一帧。count 接 open（包裹从年份墙上跳下）、top 接 months（柱子沉下、饼块升起）两处画面相接 |
| **适配三种比例** | 每种比例、每个镜头各有一行构图（锚点、占高、字幕区）。9:16 避开抖音 / 淘宝的右侧图标列和底部标题带。字幕放不下时自动缩小，缩到最小字号还放不下这条就出片失败 |
| **配乐** | D 大调、80 bpm、一小节 3 秒。命中点（包裹落地、柱子峰值、进购物车、奖牌、片尾品牌动机）都落在 0.75 秒（一拍）的网格上；同一混音渲两次逐采样一致（无头 Chromium 测，不要 GPU）。品牌动机 E4–A4–D5。WebAudio 合成 |
| **配音** | [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) 经已部署的 `kokoro-tts:live` Lambda 生成。中文 `zm_yunjian`，英文 `am_michael`。数字都写成汉字或英文单词（如「一百四十六单」/「one hundred forty-six orders」）。配音时配乐自动压低 |

### 镜头表（15 秒版）

| 时间 | 镜头 | 画面 | 字幕 |
|---|---|---|---|
| 0–2.25 s | `open` | 方块墙按日子翻面，翻出有订单的日子 | 「你的这一年」引子 |
| 2.25–4.5 s | `count` | 硬切到订单总数滚动，3.0 s 一摞包裹落地 | 年度订单数（不带数字占位，注释在大数字上） |
| 4.5–7.5 s | `months` | 十二根月柱依次升起，6.0 s 最高的一根亮起 | 最忙的月与当月订单数 |
| 7.5–10.5 s | `top` | 品类饼图扫出，最大一块滑出，9.0 s 商品落进购物车 | 复购最多的商品与次数 |
| 10.5–12 s | `title` | 年度称号奖牌落地（0.2 s 闪白切入） | 年度称号 |
| 12–15 s | `end` | 片尾卡，12.0 s 奏品牌动机（0.4 s 叠化切入） | 标语 / 双 11 到手价 / 报告上线 |

6 秒版只用三个镜头：`count`（0 s 起）、`top`（从 0.75 s 切入，闪白转场）、`end`（从 3 s 开始，叠化切入）。两版剪辑表、命中点、封面时刻都写在 `meta.js` 的 `CUTS` 里。

## 运行

ES Module 需经 HTTP 打开（`file://` 不行）：

```bash
cd opus-5.5
npm install          # 只有批量出片和测试要用
npm run serve
# 浏览器打开 http://127.0.0.1:8765/04-year-review/
```

浏览器需支持 WebGL 2。页面下方的播放器每条轴一个下拉框，可切换顾客、比例、语言、长度、活动和配音，选择会写进网址。键盘操作和通用网址参数见 [factory/README.md](../factory/README.md#预览页)。

### 变体

| 轴 | 值 | 说明 |
|---|---|---|
| `user` | `coffee` 林一 · `baby` 陈安 · `camp` 周野 · `gamer` 许星 | 数据、配色、旋律、文案跟着变 |
| `ar` | `9x16` 1080×1920 · `1x1` 1080×1080 · `16x9` 1920×1080 | 抖音 / 淘宝竖屏 · 主图视频 · Amazon 商品视频 |
| `lang` | `zh` · `en` | 字幕、价格币种（¥ / $）、配音。英文双 11 画面写 "Double 11"，配音稿写 "Double Eleven" |
| `cut` | `15` · `6` | 15 秒完整版 · 6 秒信息流版 |
| `promo` | `none` · `1111` · `launch` | 片尾卡：标语 + 查看报告 · 双 11 到手价（到手价 + 划掉的日常价）· 年度报告上线 + 分享券 |
| `vo` | `on` · `off` | 配音开 / 关，关掉时文件名加 `_novo` |

### 批量出片

需要 Node 22、Playwright 的 Chromium 和 ffmpeg（见 [factory/README.md](../factory/README.md)），出片必须用 GPU（本地无 GPU 时走 `factory/cloud.mjs` 上云）。

```bash
node factory/check.mjs 04-year-review          # 出片前自检：GPU、字体、确定性、配音、混音、字幕溢出、速度
node factory/render.mjs 04-year-review --dry   # 列出默认清单：12 条
node factory/render.mjs 04-year-review         # 出片到 04-year-review/out/
# 画廊：http://127.0.0.1:8765/factory/gallery.html?film=04-year-review（先 npm run serve）
```

默认清单 `manifest.json` 出三类交付片，每位顾客各一条：

| 内容 | 条数 |
|---|---|
| 四位 × 16:9，中文，15 秒，无活动 | 4 |
| 四位 × 16:9，英文，15 秒，报告上线 | 4 |
| 四位 × 1:1，中文，6 秒，双 11 | 4 |

共 12 条。成片文件名是 `youji_<顾客>_<长度>s_<比例>_<语言>[_<活动>][_novo].mp4`，如 `youji_coffee_15s_16x9_zh.mp4`。

### 文案与配音

文案在 `stories/<顾客>.json`（入库），由 Claude Opus 5.5 写成；重写用：

```bash
node factory/story.mjs 04-year-review --dry    # 只打印提示词，不调模型
node factory/story.mjs 04-year-review          # 真调 Bedrock（AWS_REGION、默认模型 us.anthropic.claude-opus-5-5）
```

配音片段已随仓库提交在 `assets/vo/`：64 句、约 1 MB，克隆下来就能听，不需要部署 Kokoro。重生成用：

```bash
node factory/vo.mjs 04-year-review --dry       # 列出要重生成的句子
node factory/vo.mjs 04-year-review             # 生成：需要能调 kokoro-tts:live 的 AWS 凭证
```

15 秒版三句（intro / top / end），6 秒版一句。没变的句子不重生成；放不下时段的会先提速一次，还放不下就报出这一句要改短。片段过期或缺失时出片直接报错。

## 局限

- 方块墙、图表、奖牌、商品都是程序建模，追求的是盘点动画的清晰与节奏感，不是照片级真实。
- Kokoro 的中文偶尔读错字或断错句；每句都很短且有缓存，发现问题就改写这一句重新生成。
- 语言只有中英两种，长度只有 15 秒和 6 秒。画面比例固定三种，由引擎决定（见 [factory/README.md](../factory/README.md)）。
- 无 GPU 环境下 `factory/check.mjs` 与 preview 渲染测试会因软件 WebGL 被拒而失败，这是环境限制不是代码问题；出片走云 GPU。
