# 08 · 一个包裹的旅程

有集「次日达」的物流广告：一镜到底的等距低多边形微缩沙盘，镜头沿一条对角线从手机一路推到门口——
手机下单 → 货到人仓库的机器人群 → 自动折纸箱 → 分拣线 → 月台卡车 → 公路（天色转黎明）→ 街区 → 门口暖光。

> **虚构品牌**：片中的「有集 Youji」是虚构的购物 App，沿用自 04 年度购物报告；商品、价格也取自 04 的目录。
> 片中出现的所有品牌、商品、价格均为演示用途，并非真实。

## 看点

| 看点 | 做法 |
|---|---|
| 一镜到底 | 八个工位在同一个世界里沿对角线摆开，每段 `free` 机位首尾相接，硬切处看不出跳变（6 秒版用闪白遮缝） |
| 货到人机器人群 | 约 48 台橙色 AGV 在 16×10 网格上穿行、让行、转向，互不相撞；目标那台 4.0 s 停到拣货台（见「实现」） |
| 三件商品 | 营地灯 / 电竞耳机 / 瑰夏咖啡豆（商品模型只读复用 04 的 `product.js`），换商品连门口街区配色和机器人路径一起换 |

## 运行

```bash
npm run serve     # http://127.0.0.1:8765/08-parcel-journey/?ar=16x9
```

- 轴：`item`（lantern / headset / beans）· `lang`（zh / en）· `cut`（15 / 6）· `promo`（none / 1111 / launch），外加引擎的 `ar`、`vo`。
- 交付三条：16:9 15 秒中文、16:9 15 秒英文首发、1:1 6 秒中文双11。

## 实现

机器人群路径在 `js/crowd.js`：16×10 网格、约 48 台 AGV，带时空预约表的协同 A*（cooperative A\*，按优先级逐台规划，
同一时刻不占同一格、不对穿同一条边），时间步 0.25 s、规划满 3.5 s。目标 AGV 固定 2.5 s（成片 4.0 s）到拣货台，
规划不出来就换种子重试。结果存成 `Int16Array`（同一种子逐字节相同），镜头里按 t 在相邻两格之间缓动插值、转向用最短角。
其余动作都是闭式（折纸箱、摆轮拨道、卡车发车、天色转暖、快递员走路、开门），放在 `js/world.js` 的 `update(s)` 里，`reset(ctx)` 复位。

世界沿一条对角线摆开（`meta.js` 的 lane 坐标：s 沿路、q 横向），三段地面接成一整条：夜里的书桌 → 仓库（浅水泥地、后墙货架和高窗）→
室外（马路、人行道、街边房子、路灯、树，后面一块天幕从夜蓝过渡到黎明橙）。世界只看**故事时间**（镜头在 15 秒版里的起点 + 镜头本地秒），
6 秒版从中段切入也和 15 秒版同一帧。每个镜头的机位先对准自己的主体（hold，主体落在构图表的 anchor 上），末尾再交接到下一个镜头的 hold，
所以一镜到底、切进任何一段都在主体上。片尾卡压在一块米白底板（引擎文字图层的 `panel`）上。

> 第二阶段：补齐环境、机位对准主体、6 秒版切入点、片尾卡底板。配乐细化、配音生成和批量出片在后续阶段。
