# 11 · 琉光 —— 液态玻璃主题视频工厂

这是一支 15 秒的手机主题宣传片，主角是 iOS 那种「弥散渐变 + 玻璃拟态」的液态玻璃。背景是从蓝到淡紫慢慢渐变的壁纸，上面有几团柔光色斑在漂。开场几块磨砂玻璃小组件（天气、日历、音乐；1:1 没有日历）像果冻一样依次弹出落位，接下来依次是四个镜头：
- 一块胶囊形的透明玻璃滑过数字时钟，分钟在玻璃下面从 41 翻到 42；
- 两滴玻璃分别滑过两块小组件，在中间长出液桥、相融，再拉开；
- 一整块磨砂玻璃幕从上往下扫过整屏；
- 片尾卡：一滴玻璃长成卡片，上面是品牌、标语，以及下载按钮或活动价签。

三款主题各有自己的渐变配色和配乐调性。

同一个模板可以批量出片，3 × 3 × 2 × 2 × 3 共 108 个变体，每个都有带配音和不带配音两版：
- 三种画面比例；
- 三款主题；
- 中英两种语言；
- 15 秒和 6 秒两种长度；
- 三种片尾活动。

纯静态网页：原生 ES Module + [Three.js 0.170](https://threejs.org/)（importmap 经 jsDelivr 加载），无构建步骤。这部片子没有 3D 场景，整个画面是几遍全屏着色器叠起来的；界面、玻璃、字幕和配乐都由代码生成，只有配音是预先生成、随仓库提交的 mp3。时钟、字幕排版、后期、混音、预览页、批量出片和画廊来自共用的 [factory 引擎](../factory/README.md)，本目录只有这部片子自己的数据、画面和镜头。

> 「琉光 LIUGUANG」是为本案例虚构的品牌。主题、价格和活动都是示例数据，与任何真实品牌或商品无关。

## 看点

| | |
|---|---|
| **液态玻璃** | 每块玻璃是一个二维距离场（圆角盒子，或下沿起伏的玻璃幕）。着色器按到边缘的距离算出一个穹顶形的厚度：<br>- 边缘一圈像凸透镜一样往里折射，红绿蓝三个通道错开一点，就是色散；<br>- 中间按最近的形状放大；<br>- 再叠上磨砂（先降采样再做高斯模糊）、白色薄雾、左上方来光的棱边高光、水珠一样的点状高光，以及投影。<br>四层玻璃（小组件、透镜、玻璃幕、片尾卡）各有一套质感参数，依次叠画，每层读上一层画好的结果 |
| **相融** | 同一层的形状按平滑并集（smooth min）合成一个距离场。两滴靠近时会自然长出一道液桥（花生形），不用另外建模。两滴相向而来时越来越快，正好在 7.5 s 那一拍碰上，碰上之后果冻般晃动，再上下拉开，液桥拉细、断开 |
| **弥散渐变** | 壁纸是对角渐变加五团漂移的柔光色斑。推近时壁纸只跟着走四成，所以有视差 |
| **颜色准确** | 设计稿的颜色是 sRGB。着色器先转成线性，再过一遍 PBR Neutral 色调映射的反函数，所以经过引擎后期之后，显示出来正好是设计的颜色；玻璃的高光在此之上，由色调映射自然收住 |
| **界面** | 日期、时钟、小组件里的字和图标画在一张 2D 画布上，叠在小组件的磨砂玻璃上面，后面的液态玻璃再折射它。时钟按真实字体量出字宽，等宽排列，最后一位翻页时裁在自己的数字格里。这张画布用软件光栅化：GPU 加速的 2D 画布画阴影模糊时，同一帧前后两次可能差一个色阶，会破坏确定性检查 |
| **五个镜头** | 见下面的镜头表。每个镜头只由镜头本地时间决定：拖动时间轴、跳着看和顺序播放得到同一帧 |
| **适配三种比例** | 每种比例有一套界面布局（日期、时钟、小组件、片尾卡的位置）和每个镜头的字幕区。9:16 整块往左收，让出平台的右侧图标列。字幕放不下时自动缩小，缩到最小字号还放不下，这条就出片失败 |
| **配乐** | 三款主题共用一份编曲，按各自的主音移调（鸢尾 E、晨桃 F、薄荷 D），玻璃钟的亮度和混响各不相同。15 秒和 6 秒各写一版，6 秒版不是截短的 15 秒版。利底亚调式，升四级给出玻璃一样的亮；用玻璃钟、马林巴、卡林巴和柔和的铺底。一小节 3 秒（80 bpm），命中点都在拍上：<br>- 小组件落位；<br>- 分钟翻页，和声走到二级大三和弦；<br>- 两滴相融，卡林巴两路相向，汇到同一个五度上；<br>- 玻璃幕扫过中线，玻璃钟往下撒四个音。<br>片尾的三音品牌动机（三度、七度，再解决到八度）三款共用。另有水滴、翻页的咔哒、玻璃幕的气流、转场的音效和整段的空气底噪，全部用 WebAudio 合成 |
| **配音** | [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) 经已部署的 `kokoro-tts:live` Lambda 生成，中文 `zm_yunxi`，英文 `am_michael`（与 03 相同，都是当前部署里有的音色）。配音时配乐自动压低 9 dB。数字都写成汉字或英文单词；双11 中文念「双十一」，英文念 Double Eleven |

### 镜头表（15 秒版）

| 时间 | 镜头 | 画面 | 字幕 |
|---|---|---|---|
| 0–3 s | `wall` | 主屏：画面从 1.04 倍缓缓拉到 1 倍，时钟从模糊里浮上来；磨砂小组件在 0.75、1.5、2.25 s 依次弹出落位（1:1 只有两块，落在前两拍） | 「光，有了形状」 |
| 3–6 s | `lens` | 推近到时钟。胶囊形透镜从左边滑到分钟上方，带一点过冲；4.5 s 分钟在玻璃下面从 41 翻到 42；5.1 s 起透镜往右滑出去 | 「会流动的玻璃」 |
| 6–9 s | `flow` | 两滴玻璃从左上、右下相向滑过小组件，7.5 s 相融，8 s 起上下拉开（0.3 s 叠化切入） | 「融合，分开，像水一样」 |
| 9–12 s | `sweep` | 磨砂玻璃幕从上往下扫过整屏，10.5 s 前沿扫过中线，快的时候下沿起伏更大 | 「每一处，都透着光」 |
| 12–15 s | `end` | 整屏磨砂，中间一滴玻璃长成卡片，12.6 s 落定；12.0 s 奏品牌动机（0.4 s 叠化切入） | 「琉光 LIUGUANG」、主题名、片尾活动 |

6 秒版只用三个镜头：
- `lens` 从 0.75 s 切入，0.75 s 分钟翻页；
- `flow` 从 0.75 s 切入，2.25 s 相融（叠化切入）；
- `end` 从 3 s 开始，叠化切入。

6 秒版只在片尾出字，前两个镜头一闪而过，靠配音。两版的剪辑表、命中点和封面时刻都写在 `meta.js` 的 `CUTS` 里。

## 运行

ES Module 需要经 HTTP 打开（`file://` 不行）：

```bash
cd opus-5.5
npm install          # 只有批量出片和测试要用
npm run serve
# 浏览器打开 http://127.0.0.1:8765/11-liquid-glass/
```

浏览器需要支持 WebGL 2。Three.js 和字体（思源黑体、Inter）都经 jsDelivr 加载，需要联网。字体没加载上时页面会直接报错，不会退回系统字体。

页面下方的播放器每条轴一个下拉框，可以切换主题、比例、语言、长度、活动和配音，选择会写进网址。键盘操作和通用网址参数（`t`、`paused`、`safe`、`sheet`…）见 [factory/README.md](../factory/README.md#预览页)。

### 批量出片

需要 Node 22、Playwright 的 Chromium 和 ffmpeg（见 [factory/README.md](../factory/README.md#准备)），出片必须用 GPU。

```bash
node factory/check.mjs 11-liquid-glass              # 出片前自检：GPU、字体、确定性、配音、混音、字幕溢出、速度
node factory/sheet.mjs 11-liquid-glass --theme mint --safe      # 薄荷：关键帧联系表，叠安全区
node factory/snap.mjs 11-liquid-glass --t 4.5,7.5 --ar 16x9 --lang en
node factory/render.mjs 11-liquid-glass --dry       # 列出默认清单：3 条
node factory/render.mjs 11-liquid-glass             # 出片到 11-liquid-glass/out/
node factory/render.mjs 11-liquid-glass --all       # 全部 108 个变体（配音开）；加 --vo '*' 连无配音版共 216 条
# 画廊：http://127.0.0.1:8765/factory/gallery.html?film=11-liquid-glass（先 npm run serve）
```

默认清单 `manifest.json` 出三条交付片，每款主题一条：

| 主题 | 比例 | 语言 | 长度 | 活动 |
|---|---|---|---|---|
| 鸢尾 | 16:9 | 中文 | 15 秒 | 无 |
| 晨桃 | 16:9 | 英文 | 15 秒 | 新主题上线 |
| 薄荷 | 1:1 | 中文 | 6 秒 | 双11 |

共 36 秒、1080 帧。在 EC2 g5.2xlarge（NVIDIA A10G）上用 3 个 worker（`--workers 3`）实测 2.1 分钟出完（每条 3.6–5.0 fps，16:9 慢、1:1 快），三条成片共 12.4 MB，响度 −13.3 到 −14.4 LUFS。新实例第一次从 jsDelivr 加载字体要 20 多秒，6 个 worker 同时开页可能超过 30 秒的加载时限而失败。成片文件名是 `liuguang_<主题>_<长度>s_<比例>_<语言>[_<活动>][_novo].mp4`，如 `liuguang_mint_6s_1x1_zh_1111.mp4`，封面和说明文件与成片同名。输出目录结构、断点续做规则和响度标准见 [factory/README.md](../factory/README.md#输出)。

### 配音

配音片段已随仓库提交在 `assets/vo/`：36 句，共 0.48 MB。克隆下来就能听到，不需要部署 Kokoro。
- 15 秒版三句：
  - 3.3 s 透镜滑过时钟时念「琉光，液态玻璃主题」；
  - 6.4 s 两滴玻璃相向时念「每一滴光，都会流动」；
  - 12.3 s 念品牌句或活动句。
- 6 秒版一句，从 0.5 s 开始。
- 前两句三款主题共用一条录音，双11 的片尾句也共用；每句有自己的时段上限。

改了 `copy.js` 里的台词、音色或语速后，要重新生成片段：

```bash
node factory/vo.mjs 11-liquid-glass --dry        # 列出要重新生成的句子
node factory/vo.mjs 11-liquid-glass              # 生成：需要 AWS 凭证和已部署的 kokoro-tts Lambda
node factory/vo.mjs 11-liquid-glass --audition   # 试听：每种语言四个候选音色，写到 out/audition/
```

没变的句子不会重新生成。放不下时段的句子会先提速重念一次，还放不下就报出这一句，这时要改短文案。

## 实现

```
11-liquid-glass/
├── index.html        页面：字体、importmap、boot(film)
├── meta.js           轴、剪辑表（15 / 6 秒）、命中点、镜头内的事件时刻、封面时刻、文件命名
├── film.js           成片模板：界面画布 + 玻璃着色器、复位、渲染、五个镜头、配乐、配音
├── themes.js         三款主题：名称、壁纸渐变与色斑、界面配色、价格
├── copy.js           字体、界面上的字（日期、时钟、小组件）、字幕、片尾用语、配音台词与时段
├── captions.js       各镜头的字幕图层与片尾卡的三种活动；fontsFor() 收集每个变体要加载的字符
├── layouts.js        每种比例的界面布局（UI）与每个镜头的字幕区
├── manifest.json     默认清单（3 条）
├── assets/vo/        Kokoro 配音片段 + index.json（入库）
├── js/
│   ├── motion.js     每个镜头的屏幕状态：取景、小组件落位、时钟翻页、四层玻璃的形状（纯函数，Node 测试共用）
│   ├── glass.js      全屏着色器：壁纸、磨砂小组件、液态玻璃（折射、色散、放大、磨砂、高光、投影）
│   ├── ui.js         2D 画布上的日期、时钟与小组件内容
│   └── score.js      配乐与音效
└── test/             npm test：剪辑表与命中点、构图与安全区、字幕尺寸与字体覆盖、镜头运动、配乐、配音
```

**渲染要点**
- 画面坐标用「屏幕坐标」：高度为 1，y 向下。镜头推近就是整块屏幕一起缩放、平移，界面画布和着色器用同一个取景。
- 每帧的画法：壁纸 → 小组件层（磨砂玻璃，再叠界面画布）→ 透镜 → 玻璃幕 → 片尾卡，在两张半精度浮点的全屏目标之间来回画；最后一遍直接画进引擎后期的输入。
- 镜头函数只算「屏幕状态」（`js/motion.js`），是（镜头, 本地时间）的纯函数。Node 测试直接用同一套距离场检查：透镜在翻页时盖住两位分钟、两滴在相融那一拍之前不碰、相融时有液桥、玻璃幕在 10.5 s 正好扫过中线、片尾卡落定后正好填满它的位置。

## 局限

- 玻璃是二维距离场上的近似：折射按「穹顶」轮廓估出来，不是光线追踪，也没有真实的厚度和背面反射。
- 9:16 只是粗排，默认清单不出。
- 1:1 的主屏只放得下两块小组件，但配乐和音效不分比例，15 秒 1:1 在 2.25 s 有一声水滴没有对应的小组件落位（默认清单的 1:1 是 6 秒版，没有这个镜头）。
- 语言只有中英两种，长度只有 15 秒和 6 秒。加语言要加一套文案和字体；加长度要加一个剪辑表、一版编曲和一组配音时段。
