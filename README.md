# Beyond Text · Frontier Model Showcase

用最新的大模型做文字以外的东西：网页动画、实时 3D、商品视频、配乐和配音。每个模型一个目录，目录里的案例都由这个模型动手完成，代码、素材、工具和说明都在里面。

| 模型 | 目录 | 案例 |
|---|---|---|
| Claude Opus 5.5 | [opus-5.5/](opus-5.5/README.md) | 01 临《兰亭集序》（Canvas 2D 网页动画）· 02 大力神合体（Three.js 实时 3D）· 03 香水商品视频工厂（批量出片） |

## 目录约定

- 目录名是模型名的小写短横线写法，如 `opus-5.5/`、`gpt-6-astra/`、`gpt-5.6-sol/`。
- 每个模型目录自成一体：有自己的 README、`package.json` 和工具，命令都在这个目录下执行，不引用别的模型目录里的代码。
- 案例按 `NN-name/` 编号，编号在各模型目录里各自排。
- 成片和渲染产物（`out/`）不入库。
